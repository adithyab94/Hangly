A new charm joins the collection, and the README got a clearer way to get the app.

## What's new

**Ocubli Nazar.** A twelfth collection charm: a gold-rimmed evil-eye with a
sunburst ring, drawn by hand rather than in the vector-geometry style of the
classics. Its artwork is genuinely landscape — wider than it is tall, unlike
every other charm in the collection — so it carries its own knot-placement
exception in the test suite rather than forcing a false assumption on it. A
solid gold bead sits in the gap between two sunburst spikes at the top, sized
and placed to register as a real physics bead so the rope attaches to the eye
itself, not to empty space above it.

An eye-only variant (`ocubli-nazar-onlyeye.svg`), without the "Don't Keep
Kannu" lettering, ships alongside it in `Assets/Charms/` as a design source —
not yet wired up as its own selectable charm.

**Download button.** Larger and legible in both light and dark themes on the
README hero.

## Collection count

Twelve from the collection, plus five geometric classics — seventeen charms
in total, up from sixteen.

## Verification

All 168 tests pass, including two real regressions caught by an actual
`xcodebuild test` run on a Mac: a mass/radius collision with Nazar's own
values, and a hardcoded expectation list that didn't know about the twelfth
charm.
